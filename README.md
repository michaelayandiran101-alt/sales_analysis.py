# Sales Data Analysis

## Overview
This project analyzes sales data using Python, pandas, and Matplotlib. The goal is to identify sales trends across products, regions, and months while calculating key performance indicators (KPIs).

## Tools Used
- Python
- pandas
- Matplotlib

## Analysis Performed
- Calculated total sales
- Calculated total units sold
- Calculated average sales per order
- Calculated average units per order
- Analyzed sales by product
- Analyzed units sold by product
- Analyzed sales by region
- Analyzed monthly sales
- Calculated average sales per unit by product
- Created data visualizations

## Key Skills Demonstrated
- Data cleaning and preparation
- DataFrame creation
- Datetime conversion
- Feature creation
- GroupBy aggregation
- KPI calculation
- Data visualization
- Exploratory data analysis

## Visualizations
The project generates charts showing:
1. Total Sales by Product
2. Total Sales by Region
3. Total Sales by Month
4. Average Sales Per Unit by Product
